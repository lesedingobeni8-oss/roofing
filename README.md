# Bhorholo Roofing PTY LTD Website

Responsive multi-page website prepared from the supplied Part 2 project requirements.

## Pages
- index.html — Home
- about.html — About Us
- services.html — Services
- contact.html — Contact and enquiry form

## Part 2 CSS requirements retained
- External stylesheet linked to every page
- CSS reset and base variables
- Typography family, size, weight, line-height, letter-spacing and responsive type scale
- CSS Grid and Flexbox layouts, including grid template areas
- Colour, backgrounds, borders, shadows and rounded components
- :hover, :focus-visible, :active and other pseudo-class interaction states
- Desktop, tablet (max 992px) and mobile (max 600px) breakpoints
- Relative units including rem, em, percentages and clamp()
- Responsive images using picture/srcset/sizes where appropriate
- CSS-only responsive hamburger navigation
- Blurred home cover image with a sharp overlapping image

## Enquiry functionality
The contact page saves enquiry details to the visitor's browser using localStorage. The email button opens the visitor's email application with the enquiry prepared; the WhatsApp button prepares a WhatsApp message. This does not replace a server/database. A real central enquiry database would require a backend or form service.
